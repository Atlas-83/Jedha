# Terminal
`cd` -> change directory  
`ls` -> list files and folders  
`pwd` -> print working directory  

`mkdir` -> make directory  
`touch` -> create a file`  
`mv` -> move file  
`cp` -> copy file  

`clear` -> clear terminal  

# Git
`git init` -> initialize git in a folder  
`git status` -> get status of repo  
`git add` -> add files to staging area, so that we can commit multiple modifications at once  
`git commit -m "message"` -> persist the modifications in the git history, with a message  
`git log` -> see history of project and modifications  
`git revert ###` -> revert to a commit  

`git remote add name` -> add connection to remote repo  
`git remote show` -> show remote connections  
`git push origin main` -> push changes from local to remote  
`git clone` -> copy remote repo locally # Jedha
